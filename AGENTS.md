# Global Agent Rules

## Idioma

- Responde, planifica y documenta en español.
- Mantén en inglés técnico código, identificadores, archivos, rutas, comandos, headings estándar y claves de frontmatter.
- Comentarios, `description:` y mensajes de commit: español.

## Ejecución

- No ejecutes builds, compilaciones, servidores, contenedores ni pruebas sin autorización explícita.
- Una solicitud de verificar no implica autorización para ejecutarlos.
- Puedes usar linters, formatters y comprobaciones estáticas que no ejecuten ni compilen la aplicación.

## Git

- No ejecutes `commit`, `push`, tags ni pull requests sin autorización explícita.
- Puedes inspeccionar con `status`, `diff` y `log`.

## Desarrollo

- Sigue SDD antes de implementar cambios relevantes.
- Aplica SOLID, DRY, KISS y YAGNI sin sobreingeniería.
- Prioriza componentes pequeños, cohesivos, nombres explícitos y convenciones existentes.
- Usa patrones solo cuando aporten valor.
- Señala riesgos de seguridad, escalabilidad, acoplamiento o deuda técnica.

## Agentes

- Aplica mínimo privilegio, separación de responsabilidades y trazabilidad.
- No realices acciones destructivas o irreversibles sin autorización explícita.

## Respuestas

- Sé conciso, claro y orientado a la solución.
- Usa Markdown y explica decisiones no evidentes.
